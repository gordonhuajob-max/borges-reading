# Borges 读书笔记（公开版）

一个纯静态的读书笔记网页，可直接用 GitHub Pages 打开，不需要服务器或数据库。

## 里面有什么

六本书的分章解读笔记：《认知觉醒》《学会提问》《精准表达》《穷查理宝典》《高产出管理》《把妹达人 [合集]》。

- 只有解读笔记（含少量用于说明观点的短引文），**不包含原书正文**。
- 每章可以标记 未读 / 在读 / 已读，书架显示阅读进度。
- 在笔记里点一下段落可以设置「读到这里」，选中文字可以高亮（4 种颜色）并加注释。
- 每章可以写感悟和多条笔记；「我的标记」汇总全部高亮和笔记。
- 本地全文搜索（只搜笔记和你自己的标记、笔记）。
- 「提问」：选择书、章节，可附一句笔记里的引文，把问题发给 Borges，或复制后粘贴到聊天里；答案可以粘贴回问答记录。
- 浅色 / 深色主题，适配手机。

## 数据和隐私

- 阅读进度、高亮、感悟、笔记和问答都只保存在你自己浏览器的 localStorage（键名以 `brn1:` 开头），不会上传。
- 「设置」页可以导出 / 导入 JSON 备份，用来换浏览器或换电脑。
- 「发给 Borges」用到的 Webhook 地址和 Authorization 值，由使用者自己在「设置」里填写，只存在本机浏览器（`brn1:cfg`），不在代码里，也不会进入导出的备份。

## 文件

- `index.html`：网页本体（程序、书目和章节目录）
- `data/*-notes*.js`：每本书的解读笔记，打开某本书时才加载（篇幅大的书拆成 `-notes-1.js`、`-notes-2.js` 等多个文件）
- `.nojekyll`：让 GitHub Pages 原样发布文件
